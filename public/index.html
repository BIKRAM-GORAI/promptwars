ResolveAI Capabilities Landing Page

An autonomous dispute resolution system powered by Google Gemini and integrated with Razorpay. Below is a comprehensive list of what you can test.

💳

Razorpay Integration

Enables secure payments and auto-refund payouts. Integrates seamlessly with Razorpay Checkout overlays, local HMAC-sha256 signature checks, and API refunds.

🔍

Gemini Visual Verification

Validates customer uploaded evidence photos. Prevents refund abuse by checking if the image shows the correct damaged item using zero-shot multimodal intelligence.

🍰

Granular Line-Item Claims

Allows customer claims to target specific products in bulk orders. Refund balances and auto-refund policies evaluate proportions of the single item, not the entire order.

🛡️

API & Spam Security

Enforces specialized API rate-limiting rules, CORS validations, and strict Content Security Policies (CSP) to defend against bot spam, clickjacking, and carding.

Active Test Scenarios

✔ Scenario 1: Double Charge Claim (Instant Payout)

Test the automated billing audit. The AI logs double charges, checks database payment ledgers, and processes an immediate refund.

Steps to run:
  1. View details on any order in your My Orders history.
  2. Click Report Double Charge or Billing Issue at the bottom.
  3. Type: "I was charged twice for this order" and submit.
  4. Watch the progress steps resolve and issue the refund transaction.

✔ Scenario 2: Proportional Refund (Gemini Photo Verification)

Test Gemini's multimodal cross-check. Uploading a damaged keyboard photo on a wireless mouse refund request fails validation, routing the case to manual human review.

Steps to run:
  1. Select an order with multiple items and click Request Refund next to a specific product.
  2. Upload a picture containing a completely different item.
  3. Submit the form. Gemini detects the item mismatch and routes the case to Human Review with the specific reasoning visible in the Admin Panel.

✔ Scenario 3: Return Window Exceeded Rejection

Test policy boundaries. Claims filed outside the return window configured in your environment are immediately declined.

Steps to run:
  1. File a refund request on an older order (seeded 19 days ago, exceeding your 7-day RETURN_WINDOW_DAYS).
  2. The system evaluates the timestamp difference and immediately rejects the claim, detailing the failure reason.
